# 持股复盘前端

这是一个零 npm 依赖的静态前端，用于对接本地复盘工作流 API。

## 启动后端

在项目根目录执行：

```bash
.venv/bin/python -m review_workflow serve --port 8787
```

## 启动前端

```bash
cd frontend
npm run dev
```

打开：

```text
http://127.0.0.1:5173
```

也可以直接用任意静态文件服务托管 `frontend/` 目录。默认 API 地址为：

```text
http://127.0.0.1:8787
```

## 功能

- 输入股票名称/代码、成本、持股数、计划持有周期
- 一键创建并自动执行复盘工作流
- 轮询展示截图、AI 复盘、组合摘要和文档渲染进度
- 查看每只股票的失败原因
- API 配额或余额恢复后重试失败项
- 在线阅读或下载最终 Markdown 复盘

## 注意

- 前端会把持仓提交给后端，但不会保存到浏览器以外的地方；持久化状态由后端 `workflow_state.json` 管理。
- 如果同一日期已有任务，需要勾选“覆盖同日已有任务”才会重新创建。
- 自动截图依赖后端机器上的东方财富登录态。
